## The entry

The word is **Ghosting** — the angle: the router never "drops", it ghosts — full bars, "connected", then gone without a word, back the moment you stop needing it.

One capital, no punctuation: it is written the way it would hang on the network list, so it reads as a name at a glance and needs no context.

`main.py` writes that word, and nothing else, to `/output/entry.txt`.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

Python 3.13, standard library only, no network, no randomness — the same 8 bytes every run, and no trailing newline.
